# Отчёт по лабораторно-практической работе № 4
## Тема: Работа с ветками в Git

### Цель работы
Научиться создавать ветки Git, переключаться между ними, выполнять слияние и разрешать конфликты.

### Ход выполнения

1. Создан локальный репозиторий `my-branching-repo` (папка проекта) и начальный коммит с `README.md`:
   - `git init -b master`
   - `git add README.md`
   - `git commit -m "Initial commit"`

2. Создана ветка `feature-a`, добавлен файл `feature-a.txt` и выполнен коммит:
   - `git checkout -b feature-a`
   - `git add feature-a.txt`
   - `git commit -m "Added feature-a.txt"`

3. Создана ветка `feature-b` от `master`, добавлен файл `feature-b.txt` и выполнен коммит:
   - `git checkout master`
   - `git checkout -b feature-b`
   - `git add feature-b.txt`
   - `git commit -m "Added feature-b.txt"`

4. Выполнено слияние веток `feature-a` и `feature-b` в `master`:
   - `git checkout master`
   - `git merge feature-a`
   - `git log --oneline --graph`
   - `git merge feature-b`

5. Смоделирован конфликт в `feature-a.txt`: в ветке `feature-a` добавлена строка `Conflict line from feature-a`, а в `master` — `Conflict line from master`. При выполнении `git merge feature-a` Git сообщил о конфликте содержимого.

6. Конфликт разрешён вручную: в итоговом файле сохранены обе строки. Затем изменения зафиксированы:
   - `git add feature-a.txt`
   - `git commit -m "Resolved conflict in feature-a.txt"`

7. Удалены уже слитые локальные ветки:
   - `git branch -d feature-a`
   - `git branch -d feature-b`

### Результат
В итоговом репозитории находятся `README.md`, `feature-a.txt` и `feature-b.txt`. В файле `feature-a.txt` сохранены обе строки, добавленные в ходе моделирования конфликта. История коммитов сохранена в каталоге `.git`.

### Проверка
Команды для итоговой проверки:
- `git status`
- `git branch`
- `git log --oneline --graph`

Рабочая директория чистая, текущая ветка — `master`; вспомогательные ветки удалены после слияния.

### Вывод
В ходе работы освоены создание и переключение между ветками, фиксация изменений, слияние веток и ручное разрешение конфликта. После разрешения конфликта изменения успешно зафиксированы, а завершённые ветки удалены.
